# 第三方技能安全核查

安装或首次执行来源未确认的技能前，核实来源、版本、入口、下载内容和实际权限。星数或作者声称“官方”不是安全证明。

- 阅读 SKILL.md，追踪将执行的脚本及必要依赖；重点检查联网、安装钩子、凭据访问、持久化、删除和外部上传。
- 区分完成任务所需行为与越权行为，关注混淆代码、远端下载后立即执行、窃取密钥和修改宿主安全设置。
- 不为了审计先执行未知代码；普通只读文档无需套用全部可执行程序检查。
- 说明可确认的行为、无法检查的部分及风险。用户已有安装授权可用于相符的操作；额外权限或破坏性行为需另行明确授权。
