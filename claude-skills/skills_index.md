# AI Skills Inventory Index
# AI 技能清单索引

This document provides a comprehensive overview of the specialized AI skills available in your repository. Use this as a quick reference to understand the capabilities and triggering conditions for each skill.
本页面为您提供了仓库中可用的专业 AI 技能的全面概述。请将此作为快速参考，以了解每项技能的功能和触发条件。

---

## 1. Algorithmic Art / 算法艺术 (algorithmic-art)
Creates algorithmic art using p5.js with seeded randomness and interactive parameter exploration. Use this for generative art, flow fields, and particle systems.
使用具有种子随机性和交互式参数探索的 p5.js 创建算法艺术。适用于生成艺术、流场和粒子系统。

---

## 2. Brand Guidelines / 品牌指南 (brand-guidelines)
Applies Anthropic's official brand colors and typography to artifacts. Use it when specific visual formatting or company design standards are required.
将 Anthropic 的官方品牌颜色和字体应用于工作成果。当需要特定的视觉格式或公司设计标准时使用。

---

## 3. Canvas Design / 画布设计 (canvas-design)
Creates beautiful visual art such as posters or static designs in PNG and PDF formats based on a design philosophy.
根据设计理念，以 PNG 和 PDF 格式创建美观的视觉艺术作品，如海报或静态设计。

---

## 4. Doc Co-authoring / 文档协同创作 (doc-coauthoring)
A structured workflow for co-authoring documentation, technical specs, or proposals. It guides you through context gathering, refinement, and reader testing.
用于协同创作文档、技术规范或提案的结构化工作流程。它引导您完成上下文收集、改进和读者测试。

---

## 5. Word Document Mastery / Word 文档专家 (docx)
Comprehensive creation, editing, and analysis of .docx files. Supports tracked changes, comments, and complex formatting preservation.
全面创建、编辑和分析 .docx 文件。支持修订追踪、批注以及复杂格式的保留。

---

## 6. Frontend Design / 前端设计 (frontend-design)
Builds production-grade, aesthetically pleasing web interfaces (React, HTML/CSS). Focuses on distinctive UI design that avoids "generic AI" looks.
构建生产级且美观的网页界面（React、HTML/CSS）。专注于独特的 UI 设计，避免“通用 AI”风格。

---

## 7. Internal Communications / 内部沟通 (internal-comms)
Assists in writing various internal company communications like status reports, newsletters, leadership updates, and incident reports.
协助编写各种公司内部沟通文档，如状态报告、时事通讯、领导层更新和事故报告。

## 8. MCP Builder / MCP 构架师 (mcp-builder)
A guide for building high-quality Model Context Protocol (MCP) servers in Python or TypeScript to integrate external APIs.
在 Python 或 TypeScript 中构建高质量模型上下文协议 (MCP) 服务器以集成外部 API 的指南。

## 9. PDF Processing / PDF 处理 (pdf)
A toolkit for extracting text/tables, creating, merging, and splitting PDF documents. Also handles programmatic PDF generation and form filling.
用于提取文本/表格、创建、合并和拆分 PDF 文档的工具包。还处理程序化 PDF 生成和表单填写。

## 10. PowerPoint Mastery / PowerPoint 专家 (pptx)
Creation, editing, and analysis of .pptx presentations. Includes workflows for using templates, layouts, and speaker notes.
.pptx 演示文稿的创建、编辑和分析。包括使用模板、布局和演讲者备注的工作流程。

A comprehensive guide for creating or updating AI skills that extend Claude's capabilities with specialized knowledge or workflows.

Creates and optimizes animated GIFs specifically for Slack (emojis or messages). Includes constraints, easing functions, and optimization tools.
专门为 Slack 创建和优化动画 GIF（表情符号或消息）。包括约束条件、缓动函数和优化工具。

Applies professional font and color themes to artifacts like slides, docs, or web pages. Features 10 pre-set themes and custom theme generation.
将专业的字体和颜色主题应用于幻灯片、文档或网页等工作成果。包含 10 个预设主题和自定义主题生成功能。

使用 Playwright 与本地 Web 应用程序交互并进行测试的工具包。支持 UI 验证、调试和屏幕截图捕获。

全面创建、编辑和分析电子表格。支持复杂的公式、格式化、格式标准和财务建模。
