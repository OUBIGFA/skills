# CodeGraph 按需探索

仅在当前宿主提供 CodeGraph 且目标索引可用时，用于结构查询；用户要求检查或初始化 CodeGraph 时也可使用本入口。

先查状态和索引范围，确认覆盖当前文件版本。符号搜索用 search，调用关系用 callers/callees，影响分析用 impact，集中上下文用 context/explore；具体工具名和参数以当前宿主为准。

源码是最终依据。索引陈旧、缺失、结果冲突或需检查实现时使用原生搜索与文件读取，不绝对禁止核查。不为简单查询固定调用次数，也不自动派子代理。

未初始化时普通代码任务可继续原生探索；只有任务确需索引时才在授权范围内初始化，避免因此停止原任务。
