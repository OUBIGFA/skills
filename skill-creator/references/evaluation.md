# 可选技能评估

仅在用户要求测量、触发边界有争议，或较大修改值得实验时开展；普通文档修改不必固定压力测试或循环审批。

1. 使用真实任务建立正例和相邻反例，避免用描述原话作为全部测试；改版本时保留旧版作对照。
2. 在任务 `_temp/<唯一目录>` 中运行，不触碰真实账户和生产数据。子代理、收费模型及外部动作需相应已有授权。
3. 先读 [schemas.md](schemas.md) 确认评估结构。评分必须基于输出或可观察行为，不能仅匹配技能原文。
4. Claude CLI 可用且路由已确认时，使用技能根目录的 `scripts/run_eval.py` / `scripts/run_loop.py`；先检查帮助。不要猜模型名或固定采样次数。
5. 需要多轮结果汇总时使用 `scripts/aggregate_benchmark.py`；需要人工查看产物时使用 `eval-viewer/generate_review.py`。这些脚本路径以技能根目录为准，不按本参考目录解析。
6. 区分静态检查、人工场景推演和真实模型运行，报告样本、环境、成功/失败及限制。以证据修正技能，不按固定轮数自动判通过，也不自动推送或安装。

没有独立评估工具时可检查结构和人工推演，但不能称为独立对照实验。
