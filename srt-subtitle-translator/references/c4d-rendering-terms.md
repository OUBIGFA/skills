# C4D / Rendering Subtitle Terminology

Use this reference only when translating subtitles for Cinema 4D, Redshift, 3D, rendering, motion graphics, simulation, or tutorial workflows.

## Software And Renderer Names

- Cinema 4D: keep as `Cinema 4D` or `C4D`
- Redshift: keep as `Redshift`
- Gumroad: keep as `Gumroad`
- Coloso: keep as `Coloso`

## ASR Corrections Seen In Similar Tutorials

- `cam model` -> `can model` when the subject is a beverage can
- `negative wire` -> `negative Y` in transform/orientation context
- `cool sticks` -> `Caustics` in Redshift render settings
- `site` -> `size` when adjusting a particle group or object scale
- `points free` -> `0.3` when discussing small numeric settings

## Style Notes

- Keep UI path names in English when the viewer must find them in software
- Translate descriptive narration into concise Chinese
- Do not translate filler words such as `Yeah`, `OK`, `Nice`, `Cool`, `Uh`, `Um` unless they are UI labels or meaningful adjectives
